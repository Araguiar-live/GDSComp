# Ana Rafaela Aguiar — Portfolio 2.0

Personal selected-works site for Ana Rafaela Aguiar. Restored from the in-progress GitHub repo [GIRL23RAF/Portfolio2.0](https://github.com/GIRL23RAF/Portfolio2.0), including the latest CRCLE Figma work and profile credentials panel (`cursor/crcle-figma-and-profile-credentials`, backup from 25 Aug 2026).

The homepage is a single-page case-study layout: project accordion, dock navigation, and interactive mockups for **CRCLE**, **First Design**, **Odicci**, and **Ambitious Peace**.

## Run locally

Requires Node.js 22+.

```bash
npm install
npm run dev
```

Then open the URL Vite prints (typically `http://localhost:5173`).

```bash
npm run build
npm run preview
```

## Stack

TanStack Start, React, Vite, Tailwind CSS, Framer Motion, and shadcn/ui.

Source of truth while editing was GitHub. This Origin copy is the restoration workspace.
